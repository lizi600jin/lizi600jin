### 代表项目

- [**hifi-src-bypass**](https://github.com/lizi600jin/hifi-src-bypass) [![stars](https://img.shields.io/github/stars/lizi600jin/hifi-src-bypass?style=flat-square&color=6e7681)](https://github.com/lizi600jin/hifi-src-bypass)  
  全机型 Android 音频直通。逐层解除策略 XML、USB HAL 采样率表、厂商 HiFi 通道、音量曲线四处上限，消除系统级重采样；96k → 384k，16 / 24 / 32 bit，配 WebUI 与 `hifi doctor` 深度校验。

- [**hakios-xaga**](https://github.com/lizi600jin/hakios-xaga) [![stars](https://img.shields.io/github/stars/lizi600jin/hakios-xaga?style=flat-square&color=6e7681)](https://github.com/lizi600jin/hakios-xaga)  
  XNU（Darwin Kernel 22.5.0）与 iOS 16.5 用户态跑在天玑 8100 上，已点亮桌面：引导链 LK → mtkloader → XNU，UFS 读取 APFS，1080×2460 / 60 fps。实验性项目，触控、USB、GPU 尚未完成。

- [**oneplus13-audio-effect**](https://github.com/lizi600jin/oneplus13-audio-effect) [![stars](https://img.shields.io/github/stars/lizi600jin/oneplus13-audio-effect?style=flat-square&color=6e7681)](https://github.com/lizi600jin/oneplus13-audio-effect)
